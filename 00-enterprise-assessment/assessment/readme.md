# Phase 0 — Enterprise Assessment

## Executive Summary

AFG Enterprises has expanded its Azure footprint through
organic cloud adoption without a unified enterprise architecture
and governance framework.

The assessment identified inconsistencies across management
groups, subscription governance, identity, network security,
logging, policy enforcement, resource ownership, privileged
access, and configuration management.

The primary challenge is not the absence of security technology.

The challenge is that existing security capabilities are not
consistently governed, automated, measured, or enforced across
the enterprise.

## Assessment Objectives

The assessment evaluates:

- Azure organizational structure
- Subscription governance
- Identity and privileged access
- Network architecture
- Security monitoring
- Azure Policy
- Workload credentials
- Data protection
- DevSecOps maturity
- Resource ownership
- Governance processes

## Key Findings

1. Cloud governance has not matured at the same rate as Azure adoption.
2. Management-group architecture requires modernization.
3. Policy enforcement is inconsistent.
4. Resource ownership relies too heavily on institutional knowledge.
5. Privileged access requires stronger lifecycle governance.
6. Security telemetry is not uniformly deployed.
7. Infrastructure configuration requires greater automation.
8. Security exceptions require formal lifecycle management.

## Transformation Recommendation

The assessment recommends a phased enterprise transformation:

Phase 1 — Azure Landing Zone  
Phase 2 — Cloud Governance  
Phase 3 — Zero Trust Identity  
Phase 4 — Network Modernization  
Phase 5 — Security Operations  
Phase 6 — DevSecOps  
Phase 7 — Data Protection  
Phase 8 — AI Security
