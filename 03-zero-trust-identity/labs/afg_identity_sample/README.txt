AFG Synthetic Identity Dataset — Phase 3
========================================
Generated by generate_afg_identity_data.py, seed 42, 150 users.
Purely fictional lab data. Never use as real production identity records.

users.csv: employee profiles, UPNs, manager references, employment status.
departments.csv: department records and manager employee IDs.
groups.csv: simulated security groups, group categories, sensitivity flag.
group_memberships.csv: simulated user-to-group assignments.

UPNs use the reserved example.test namespace. No real Entra/SailPoint
accounts, directory groups, or access permissions are created.

Scenario tests:
- Joiner: create a new HR record; expect birthright departmental access.
- Mover: change department; remove previous and grant new birthright access.
- Leaver: Terminated users have no group memberships in snapshot.
- SoD: Finance AP processors and approvers use separate groups.
- Privileged: Azure-Privileged-Eligible is only a modeled eligibility group.

These CSVs are data for a future import/transform, not an import format
certified for a specific SailPoint connector or Entra provisioning tool.
